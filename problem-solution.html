牙疼

持续疼痛 / 冷热敏感

查看原因

牙疼的可能原因

深龋

细菌侵蚀到牙本质深层，冷热酸甜刺激引发疼痛，是最常见的牙疼原因。早期可能只有冷热敏感。

早期可补牙修复

牙髓炎

蛀牙未及时治疗，细菌感染牙髓（牙神经），引起剧烈疼痛，尤其是夜间疼痛加剧。

需根管治疗

根尖周炎

牙髓炎继续发展，炎症扩散到牙根尖周围组织，牙齿浮起感、咬合时疼痛明显。

需根管治疗

牙周脓肿

严重的牙周炎导致牙周袋内细菌感染化脓，牙龈红肿、胀痛，可能伴有发热。

需牙周治疗

智齿冠周炎

智齿萌出不全，牙冠周围牙龈瓣发炎，张口受限、吞咽疼痛。常见于18-30岁人群。

需拔除智齿

牙隐裂

牙齿表面出现细微裂纹，咬合时疼痛明显，多见于咀嚼硬物后，裂纹可延伸至牙根。

需全冠修复

蛀牙

牙齿黑点 / 食物嵌塞 / 冷热敏感

查看原因

蛀牙的成因与发展

细菌侵蚀

致龋菌分解食物中的糖分产生酸性物质，持续侵蚀牙釉质，使矿物质流失形成蛀洞。

所有蛀牙的根源

早期（浅龋）

牙釉质表面出现白垩色或褐色斑点，没有明显疼痛。此时补牙最简单。

可一次补好

中期（中龋）

蛀牙发展到牙本质层，对冷热甜酸产生敏感刺激。此时仍可保留牙神经。

需去腐充填

深龋 → 牙髓炎

蛀洞接近或已穿透牙髓腔，引发牙髓炎，出现自发痛、夜间痛。需根管治疗。

需根管治疗

缺牙

牙齿缺失 / 邻牙倾斜 / 咀嚼困难

查看原因

缺牙的原因与修复方式

严重龋坏

蛀牙发展到无法保留的程度，是导致缺牙最常见的原因。牙体组织大部分丧失，无法通过补牙修复。

需拔除后修复

牙周病

严重的牙周炎导致牙槽骨吸收、牙齿松动脱落。是成年人缺牙的主要原因之一。

需牙周+种植

外伤脱落

因意外撞击、摔倒等导致牙齿完全脱位或折断无法保留。需立即就医处理。

需紧急处理

先天性缺牙

先天性的牙胚缺失，最常见于第三磨牙（智齿）和侧切牙。需根据情况修复。

需修复治疗

牙齿矫正

牙齿不齐 / 地包天 / 牙缝过大

查看原因

需要正畸的常见情况

牙齿拥挤

牙弓长度不足以容纳所有牙齿，导致牙齿排列不齐、重叠。不易清洁，易患龋齿和牙周炎。

最常见错𬌗畸形

地包天（反𬌗）

下牙咬在上牙外面，影响面部美观（月亮脸），还可能影响咀嚼功能和颞下颌关节健康。

建议早期矫治

龅牙（深覆盖）

上前牙过度前突，下前牙位置靠后。容易造成外伤性折断，影响唇部闭合和面部美观。

需正畸治疗

牙缝过大

牙齿之间有过大的间隙，影响美观且容易嵌塞食物。可能因牙齿过小或先天性缺牙引起。

可矫正或修复

开𬌗

咬合时前牙不能接触，形成梭形缝隙。影响发音和切割功能，常伴有吐舌习惯。

需正畸+肌功能训练

埋伏牙

牙齿未能正常萌出，埋伏在颌骨内，常见于尖牙和智齿，可能压迫邻牙牙根。

需外科+正畸联合
